# Diagram rubric

Standing reference for building diagrams for the blog. The bar: a diagram
must show something the prose cannot.

## Principles

- **Metaphor first.** The image communicates before any label is parsed.
- **Contrast over pipeline.** Old/new, open/closed, immediate/future — not
  a row of boxes with arrows.
- **Color encodes something specific** — a state, an intervention, a
  difference. Never decorative.
- **Annotations point into the drawing**, not floating above generic shapes.
- **Break symmetry.** Uneven breathing room, overlap, controlled bleed.
- **Vary stroke weight** slightly; nothing mathematically perfect.
- **Every accent-colored mark and decorative element must earn its place.**

## Motion

Movement captures attention automatically. Use it as a spotlight: point it
at the idea itself, never as decoration. (Set when the brainrotco diagram
was reframed from "the mismatch" to "movement is a spotlight.")

## AI-slop tells — avoid all of these

- Centered, evenly spaced compositions.
- Default boxes-and-arrows structures.
- Labels that merely restate the prose.
- Decorative dotted baselines or marks that encode nothing.
- Perfect circles, identical stroke weights, mathematical spacing.
- Accent color used decoratively instead of semantically.

## Process

1. What's the one idea this diagram exists to land?
2. What's the visual metaphor — what does the reader *see* before reading?
3. What does color encode? (If nothing: remove the color.)
4. Squint test: blur the labels. Does the drawing still say something?
5. Prose test: cover the diagram. Does the prose lose something real?
   If not, the diagram is decoration — cut it or redraw.
